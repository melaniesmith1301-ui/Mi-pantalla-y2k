# Mi Pantalla Y2K 🎀

Mi primer proyecto de programación. Un widget interactivo estilo Y2K con reloj en vivo, clima real y animaciones.

**Ver online:** https://melaniesmith1301-ui.github.io/Mi-pantalla-y2k/

### Qué hace
- Reloj en vivo que se actualiza cada segundo
- Saludo dinámico según la hora del día
- Clima real de Buenos Aires con API de Open-Meteo (gratis, sin clave)
- Frases aleatorias / afirmaciones
- Animación de Lana Del Rey con giro 3D al pasar el mouse
- Reproductor de Britney Spears - Break The Ice
- Diseño responsive para celu y compu

### Tecnologías
HTML, CSS (Grid, Flexbox, animaciones), JavaScript (fetch, setInterval, DOM)
